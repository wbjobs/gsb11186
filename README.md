# 多标签页实时日志聚合

一个无构建步骤的静态页面，使用 BroadcastChannel 在多个浏览器标签页之间实时聚合日志。

## 运行

```bash
python3 -m http.server 8080
```

打开 `http://localhost:8080`，再复制 3 个标签页即可验证 4 标签页同时写入。

## 功能

- 写入 debug / info / warn / error 日志
- 多标签页实时聚合和一致排序
- 按级别筛选、清空
- 新标签页加入时通过快照补齐日志
- 标签页关闭广播 bye，异常关闭时通过心跳超时移除
- 最多保留 10000 条，超出后丢弃最旧日志
- 高频写入按 40ms 窗口合并，广播批次最多 500 条
- Canvas 展示最近 60 秒日志量曲线

## 测试

```bash
npm test
```

测试覆盖四标签页并发写入、乱序到达、一万条截断、高频合并、清空收敛、标签页关闭、新标签页快照同步和真实 BroadcastChannel 传输。
