# 多标签页日志聚合 Demo

多个浏览器标签页同时写入日志（级别 / 时间 / 消息），所有标签页通过
`BroadcastChannel` 实时看到一致的聚合日志列表，支持按级别筛选、一键清空，
并用 Canvas 绘制最近 60 秒的日志量曲线。

## 运行

```bash
# 任意静态服务器均可（BroadcastChannel 要求同源，file:// 下部分浏览器可用）
python3 -m http.server 8000
# 打开 4 个标签页访问 http://localhost:8000/index.html
```

每个标签页可手动写入，或开启「自动写入」（10 / 100 / 500 条每秒）压测。

## 测试

```bash
node test.mjs   # 35 项断言，覆盖全部验收标准
```

## 文件

- `index.html` — 页面：写入控制、筛选、清空、日志列表、Canvas 曲线、在线标签页数
- `log-core.js` — 核心逻辑（浏览器 / Node 通用）：`LogStore`（去重、有序插入、截断、清空水位线）、`Batcher`（高频合并）
- `test.mjs` — 基于真实 `BroadcastChannel` 的多标签页集成测试

## 关键设计

| 问题 | 方案 |
|---|---|
| 同时写入 | 每条日志全局唯一 id（`tabId:seq`），各标签页独立聚合、按 id 去重 |
| 消息乱序 | 按 `(time, id)` 二分插入，任意到达顺序收敛到同一确定序 |
| 标签页关闭 | `beforeunload` 广播 `bye` + 2s 心跳 / 5s 超时剔除；其余标签页不受影响 |
| 超过 1 万条 | 丢弃最旧、保留最新，计数展示「已截断 N 条」 |
| 高频写入 | `Batcher` 每 100ms 或满 50 条合并为一次广播；渲染合并到每帧一次 |
| 清空并发 | 清空携带时间水位线，晚到的旧日志与同步快照一律丢弃 |
| 新标签页 | 上线广播 `hello`，其他标签页回传快照完成历史同步 |
